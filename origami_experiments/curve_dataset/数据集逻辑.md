## 0. 设计哲学

借鉴 **GraphMetaMat**：不再把折纸响应压成 6 个刚度标量，而是**把每个加载工况的完整非线性力-位移路径离散成数组保存**。一句话——**同一批结构，把「6 个标量」升级成「6 条曲线」**。

## 1. 数据来源：复用刚度数据集的参数

`prepare_curve_jobs.py` **不重新采样参数**，而是直接读刚度数据集的源文件
`external/.../MaterialProperty/{Miura,TMP}SheetMat.txt`，取前 8 列设计参数作为输入：

- v2 用 `--source miura`（仅 `pattern=1`），**2000 个样本**；`sample_id = miura_00001…`。
- 原 6 个刚度标量**保留在 `parameters.csv` 仅供 QC / 载荷缩放，不作 ML 目标**。

→ 曲线数据集与刚度数据集**输入参数空间完全相同**（8 维：`pattern, m, n, tcrease, tpanel, W, creaseE, panelE`），只是把"目标"换成更丰富的曲线。

## 2. 6 个加载工况（硬编码 condition schema）

| curve_id | load_case | deployment（展开率） | 响应轴 |
|---|---|---|---|
| 0/1/2 | bending | 0.3 / 0.6 / 0.9 | z |
| 3/4/5 | axial | 0.3 / 0.6 / 0.9 | x |

每个样本在 6 个工况下各跑一条曲线，每条 **80 个加载步**（v1 是 30）。

## 3. 仿真逻辑 + 材料

来源：`GenerateOrigamiForceDisplacementCurves.m`（驱动）+ SWOMPS `Mesh_MechanicalProperty.m`（材料/刚度）。

### 3.1 仿真引擎：SWOMPS「杆-铰」(bar-and-hinge) 降阶模型

**不是有限元**，而是把折纸离散成：

- **面板 → 三角化的杆 (bar) + 对角弯曲弹簧**（面内拉伸 + 面外弯曲）
- **折痕/折线 → 旋转铰弹簧 (rotational hinge spring)**（折叠）

### 3.2 几何（`buildOrigami`）

- 整体尺寸 `L = 0.2 m` 的折纸天篷；Miura 折叠角 `γ = 70°`；`m×n` 个单元格；
- 在某个**展开率 deployment（0.3 / 0.6 / 0.9）**下成形后再加载；
- 网格 `mesh2D3D = 3`（厚板），`compliantCreaseOpen = 0`（折痕用集中铰，不展开为柔性折痕网格）。

### 3.3 材料：线弹性各向同性（参数化扫描，非具体牌号）

材料就是一组线弹性常数：

| 属性 | 取值 | 说明 |
|---|---|---|
| 面板模量 `panelE` | **采样 [1, 5] GPa** | 输入参数 |
| 折痕模量 `creaseE` | **采样 [1, 5] GPa** | 输入参数（与 panelE 独立） |
| 泊松比 `panel/creasePoisson` | **0.3（固定）** | 面板与折痕都是 0.3 |
| 密度 `ρ` | **1200 kg/m³（固定）** | 折痕与面板同密度 |
| 屈服 / 塑性 | **无** | 纯弹性，无失效 |

→ E∈1–5 GPa、ρ≈1200、ν=0.3 对应**刚性聚合物/塑料量级**（亚克力/PET/PC、3D 打印料、厚纸板这一档），是**通用参数化弹性材料**而非某个具体牌号——"材料"通过 `creaseE` / `panelE` 扫出来。

### 3.4 材料模量如何进入刚度（`Mesh_MechanicalProperty.m`，集中铰分支）

- **折痕铰刚度**：`kHinge = creaseE/12 · tcrease³ / W`，再 ×杆长 → ∝ **creaseE · tcrease³ / W**
- **面板弯曲弹簧**：`kSprPanel = panelE/12 · tpanel³ / W` → ∝ **panelE · tpanel³**
- **面板杆面积**：`aPanel ∝ tpanel · 面积`，杆轴力用 panelE → 面内刚度 ∝ **panelE · tpanel**

厚度 `tcrease/tpanel`、折痕宽 `W` 与模量 `E` 共同决定刚度（铰/弯曲项 ∝ t³，对厚度极敏感）。

### 3.5 加载：Newton-Raphson 增量力加载（几何非线性）

`ControllerNRLoading`，`increStep = 80` 步，`tol = 1e-7`：

- **边界条件 = 悬臂**：x 最小端节点**全约束**（3 DOF 全固定），x 最大端节点**施力**。
- **加载方向**：bending → 沿 **−z**；axial → 沿 **+x**。
- **力是控制量、位移是响应**：力按 80 步线性递增，每步解出节点位移，位移取施力端沿加载轴的平均 `mean(|u|)`。
- **自适应载荷 `stiffness_scaled`**（关键）：
  ```
  finalLoad = referenceStiffness × TargetLinearDisplacement(0.015)，封顶 MaxFinalLoad(10000 N)
  ```
  `referenceStiffness` 取该样本**原刚度数据集对应的刚度标量**（curve 0 用 bendstiff30…），让每个结构在线性段都变形到 ~0.015 m，不同刚度样本因此可比；实测被 cap 的样本 force 上限正好 10000 N。
- **非线性来自几何**（大折叠转动，NR 每步更新构型），**不是材料非线性**。

### 3.6 物理量提取（7 通道，来自 SWOMPS 求解器历史）

- `strain_energy_{total,crease,panel}`（由 `strainEnergyHis` 4 列重组：1+4=折痕/弹簧，2+3=面板/杆）
- `max_bar_stress`（barSxHis）、`max_bar_strain`（barExHis）
- `max_crease_moment`（sprMHis）、`max_crease_rotation`（sprRotHis）

每样本导出一个 `raw_curves/{sample_id}.csv` = **480 行(6×80) × 21 列**。

## 4. 打包逻辑（`build_curve_dataset_npz.py`）

```text
parameters.csv + condition_schema + simulation_jobs（一致性校验）
   → 逐样本读 {sample_id}.csv，stack 成 [6 工况, 80 步]
   → 严格校验：step 必须正好 1..80、无 NaN/Inf、全部收敛、7 物理量齐全
   → (可选) 质量过滤：剔除 max_displacement / max_bar_strain / max_bar_stress / max_physics_abs 超阈样本
   → 划分 train/test
   → StandardScaler 分别标准化 X(8 维) 与 y，仅在训练集 fit
   → 存 npz + scaler + train/test_samples.csv + metadata.json
```

**模型目标 `y` = 位移（仅位移）**，展平成 `6×80 = 480` 维（`y = displacement.reshape(N, -1)`）。力不是目标——作为控制量存在 `force_raw` / `curve_raw`（部分 forward 变体会把力作条件输入）。

### npz 内容（一份样本 = 一行）

| 键 | 形状 | 角色 |
|---|---|---|
| `X` / `y` | (N,8) / (N,480) | 标准化输入 / 标准化位移目标 |
| `X_raw` / `y_raw` | (N,8) / (N,6,80) | 原始参数 / 原始位移 |
| `force_raw` | (N,6,80) | 力（控制量） |
| `curve_raw` | (N,6,80,2) | [位移, 力] 完整曲线 |
| `physics_raw` | (N,6,80,7) | 7 物理量 |
| `converged` | (N,6,80) bool | 收敛标记（实测全 True） |
| `sample_id` / `condition_*` / `input_cols` / `physics_cols` | — | 元数据 |

## 5. 划分策略与已打包版本

`split_indices` 支持三种（与刚度数据集一致）：

| 划分 | 逻辑 | 用途 |
|---|---|---|
| `random` | 8:2 随机（seed=42） | 基线 |
| `group_pattern_mn` | 按 `pattern_m_n` 分组（`GroupShuffleSplit`） | 未见结构族泛化 |
| `extrapolate_high_W` | 按 `W` 降序，最大的一批留作测试 | 折痕宽外推 |

磁盘上已生成 3 个打包版本：
- `data/`（group 划分，train 1570 / test 430）
- `data_random/`（1600 / 400）
- `data_random_quality_filtered/`（1599 / 400，质量过滤掉 1 个）

## 6. 质量控制

- `audit_curve_batch.py`：要求 0 结构性问题、全收敛、且**非线性度达标**（平均割线刚度变化比 > 0.08、线性偏离 > 0.08）——确保曲线确实非线性、值得用曲线而非标量。
- 实测：**2000 样本 100% 收敛**；力/位移均单调递增；割线刚度 end/start 比值 mean≈1.09（多数**轻微硬化**）。

## 7. 与刚度数据集的关系 + 驱动呼应

| | 刚度数据集（→ `demo_data/`） | 力-位移曲线数据集（默认） |
|---|---|---|
| 输入 | 同样 8 参数 | **同一批 8 参数** |
| 目标 | 6 个刚度标量 | 6 工况 × 80 步**位移曲线** + 7 物理量 |
| 信息 | 线性刚度（初始斜率） | 完整非线性加载路径 |
| 来源 | SWOMPS（直接给标量） | SWOMPS NR 重新仿真整条曲线 |

材料模型与之前的刚度驱动分析完全一致：

- **轴向加载**（+x 拉伸"手风琴"）主要让**折痕折叠** → 由 `creaseE / tcrease / W` 主导；
- **弯曲加载**（−z）主要让**面板弯曲** → 由 `panelE / tpanel` 主导；
- `creaseE` 对弯曲相关性≈0，正因为弯曲几乎不动折痕铰——物理模型与数据互相印证。

## 8. 关键数据特征（实测）

- 2000 样本，全 Miura；6 工况 × 80 步；100% 收敛。
- 力 ≤ 10000 N（自适应封顶）；位移 ≤ ~0.074 m；力、位移均单调递增。
- 割线刚度 end/start ≈ 1.09（轻微硬化）——捕捉到真实几何非线性。

---

> **物理保真度提醒**（SWOMPS README 原话）：杆-铰是降阶模型，刚度由"匹配板理论(拉/剪) + 伪刚体(大折叠)"解析推导，**对非刚性可折叠折纸可能高估刚度**。这是快速趋势级仿真，不是高保真 FEM。
