# Origami Sheet 数据集模型训练实验报告

**日期**: 2026-05-08 | **数据来源**: Miura + TMP Origami Sheet (MaterialProperty 版本)

---

## 1. 实验目标

使用 TPMS 项目中的 4 种模型架构（GAT、Transformer、CVAE、Diffusion + ResNet），在 Origami Sheet 折纸天篷刚度数据集上从零训练，完成：
- **正向预测**（8 个设计参数 → 6 个刚度值）
- **逆向预测**（6 个刚度值 → 8 个设计参数）

不改变模型核心架构，仅适配输入/输出维度。

---

## 2. 数据概况

| 项目 | 说明 |
|------|------|
| 来源 | MiuraSheetMat.txt + TMPSheetMat.txt |
| 总样本 | 4000（训练 3200 / 测试 800） |
| 输入特征 | pattern, m, n, tcrease, tpanel, W, creaseE, panelE (8) |
| 输出目标 | bendstiff30/60/90, axialstiff30/60/90 (6) |
| creaseE/panelE 范围 | 1×10⁹ ~ 5×10⁹ Pa |
| 刚度值范围 | 10² ~ 1.4×10⁶ |

## 4. 模型架构适配

所有模型保持与原 TPMS 相同的层级结构，仅改动输入/输出维度：

| 模型 | 原维度 | 新维度 | 架构要点 |
|------|--------|--------|----------|
| GNNForward | 9→20 | 8→6 | 8 参数节点全连接图, 2×DenseGATConv, ResMLP 解码器 |
| ForwardTransformer | 9→21 | 8→6 | 参数 token化 + 类型编码 + [CLS] + 4层 TransformerEncoder |
| ResNet1DInverse | 20→9 | 6→8 | Conv1d backbone, 4个 ResNet block, AdaptiveAvgPool1d |
| CVAE | 20→9 | 6→8 | Conv1d 曲线编码器, latent_dim=4, 条件 dropout |
| Diffusion | 20→9 | 6→8 | DDPM, T=300, 预测 epsilon, EMA decay 0.99, x0 辅助损失 |

## 6. ResNet 逆向模型调优历程

原始配置训练后 val loss 在 epoch 50 即平台化，经过 4 轮调优：

| 轮次 | 关键改动 | 最佳 Val |
|------|----------|----------|
| 第1轮 (原始) | lr=2e-4, noise=0.01→0, patience=20, dropout=0.1 | SmoothL1=0.190 |
| 第2轮 | lr=1e-3, patience=40, noise=0.003, factor=0.6 | SmoothL1=0.182 |
| 第3轮 | 改为 MSE, dropout=0.3, noise floor=0.001 | MSE=0.353 (变差) |
| **第4轮 (最终)** | 回到 SmoothL1, dropout=0.2, noise floor=0.0005 | **SmoothL1=0.172** |

核心结论：MSE 对标准化后的参数预测不利，SmoothL1 更鲁棒；适度噪声底限（0.0005）有助于防过拟合。

## 8. 结论

### 正向预测

- GNN 和 Transformer 都能**几乎完美**地从设计参数预测刚度响应（R² > 0.999）
- 6 个弯曲/轴向刚度输出的 NRMSE 均 < 0.4%

### 逆向预测

- **pattern 识别**：三个模型都能近乎完美区分 Miura vs TMP（R² > 0.99）
- **几何参数 (m, n, tpanel)**：ResNet 整体最优（R² 0.84-0.96），可较好反推
- **厚度/宽度 (tcrease, W)**：所有模型较难预测（R² 0.2-0.45），这些参数对刚度的影响可能被其他因素掩盖
- **材料模量 (creaseE, panelE)**：逆向预测最困难（R² 0.07-0.56），存在固有物理歧义——不同的几何×材料组合可产生几乎相同的刚度曲线

### 模型对比

| 维度 | 最佳模型 |
|------|----------|
| 正向预测 | GNN ≈ Transformer（无显著差异） |
| 逆向 pattern | CVAE（R²=0.998） |
| 逆向几何参数 | ResNet（R² 均值最高） |
| 逆向材料参数 | CVAE（但整体仍低） |
| 训练速度 | ResNet > GNN > Transformer > CVAE > Diffusion |
| 泛化稳定性 | ResNet > Diffusion > CVAE |

### 核心发现

逆向问题存在**一对多映射**：同一条刚度曲线可对应多组几何+材料参数组合。这是物理上的根本困难，不是模型能力问题。要改善逆向预测精度，需要考虑：
1. 增加约束条件（如固定材料参数）
2. 输出参数分布而非单一确定值（CVAE/Diffusion 已具备此能力）
3. 使用更大更多样化的训练数据
