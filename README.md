# TPMS 实验数据与逆向设计工作区

本工作区仅保留三周期极小曲面（TPMS）相关的几何编译、数据生成、代理建模和逆向设计内容，作为后续实验数据集与研究代码的工作区。

## 保留内容

- `paper_A_reliable_inverse_design/`：可靠逆向设计与 graded Gyroid 几何编译流程。
- `paper_B_spatial_algebraic_tpms/`：空间/代数 TPMS 主线及 TPMS 数据生成、验证与均匀化流程。

## 使用约定

- 新的 TPMS 数据、模型权重、验证结果和实验报告应归档到对应的 TPMS 子项目中。
- 根目录仅保留共享配置、通用缓存和项目级说明，不再放置其他材料体系的数据或实验产物。
- 大型可再生数据和模型权重按 `.gitignore` 规则处理；提交前请确认文件属于 TPMS 实验。
