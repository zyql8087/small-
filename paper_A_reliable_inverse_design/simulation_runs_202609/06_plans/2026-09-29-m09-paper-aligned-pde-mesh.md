# M09 实验计划:论文完全对齐管线(PDE 网格 + Explicit + z 向 + 周期边界)——师弟执行版

> **执行人**:师弟(本计划自包含;执行环境=师弟机,Abaqus 2023 或 2025 均可)。
> **决策链**:2026-09-29 用户拍板"走路线 ③,完全和作者文章里对齐"。本计划取代 M08 的 STL→gmsh 网格路线;M08 结果留作对照,不推翻、不重算。
> **核心判断(为什么这条路线能治起步瞬态)**:我们 M08 的起步瞬态根因=STL 三角汤(3µm 碎边)被 gmsh 继承为边界单元→质量缩放灌出 65 万倍假质量。作者论文写明的 PDE 网格法**不继承 STL 三角形**(STL 仅作边界定义,网格由工具箱按尺寸 0.05/增长率 1.2 重新生成+内置质量控制)→ 无 µm 单元 → **质量缩放可能完全不需要**(见 §6)。这是"作者没出现这个问题"的论文版答案,也是本计划的验证目标。

## 2. 新管线总览

```
编译器 STL(边界定义)→ MATLAB PDE geometryFromMesh → generateMesh(HMax=0.05,HGrad=1.2,二次)
→ 节点/单元导出 + Abaqus C3D10 排序映射 → 求解 INP(材料 A7 逐字节 + A4/A5/A6 卡)
→ datacheck → 显式求解 → 提取(RF3 求和/U3/能量)→ 对照表(§7)
```

## 3. 网格生成(MATLAB,每例)

- [ ] 读入编译器 STL(`stlread` 或既有读取器),构 `triangulation`,`fegeometry(geometryFromMesh(T))`;
- [ ] `generateMesh(gm, HMax=0.05×半跨物理值, HGrad=1.2, GeometricOrder="quadratic")`;记录元素数/节点数/最小边;
- [ ] **质量门(自检,不过则该例记 failed-mesh 不进求解)**:① 全部四面体体积>0 且有向一致;② 最小边 ≥ 0.02×HMax(µm 特征即失败——本路线的核心验证点);③ 畸变(aspect)分布记录;④ 边界闭合(面流形:每内部面恰 2 单元);
- [ ] 导出节点(含 midside)与单元连接表 → `mesh_report.json`(含 HMax/HGrad/元素数/质量统计)。

## 4. INP 组装(关键坑,逐条过)

- [ ] **C3D10 节点排序映射**:MATLAB PDE 二次四面体的角点+中点排序 ≠ Abaqus C3D10(边序 5=(1,2),6=(1,3),7=(1,4),8=(2,3),9=(2,4),10=(3,4))。**映射后必须自检有向体积>0**;Abaqus datacheck 的负雅可比报错=映射错的探测器,逐例以 datacheck 通过为准;
- [ ] 材料卡:从 06 包逐字节复制(poly2 超弹+塑性),禁止重打字;
- [ ] 节点集:底面(z=z_min 平面节点)/顶面(z=z_max)/x±、y± 面(周期配对用);
- [ ] 步卡:`*Dynamic, Explicit`,T 见 §6;`*Amplitude, SMOOTH STEP`;
- [ ] 输出:场 U,S,SENER(20 区间);历史 ALLIE/ALLKE/ALLAE/ALLPD/ETOTAL + 顶面集 U3/RF3(逐节点,提数用);
- [ ] **质量缩放卡:默认不加**。仅当 datacheck 后预计增量数>2×10⁷ 时才加 `*Fixed Mass Scaling, type=BELOW MIN, dt=…`,并在报告记录缩放质量占比(须<1%)。

## 5. 周期边界(x/y,实现规格)

- [ ] 对每对对面(x−/x+):两侧节点按坐标最近邻配对(容差=网格节点间距×0.01);**配对数必须两侧相等**,不等则该例 failed-bc;
- [ ] 每对生成 `*Equation`:U1(或 U2) 两侧差=0(注意驱动方向 z 不周期约束);
- [ ] 顶面 U1=U2=0(不是全周期——论文:上表面除 z 外全固),底面全固;
- [ ] **若最近邻配对在本几何上不可行**(边界三角化两侧节点数不等),回退=六面法向固定 BC(M08 口径),并在报告标记 `bc_deviation=normal_fix`(不得静默)。

## 6. 显式参数(工程选择,全部记录)

| 参数 | 初值 | 依据 |
|---|---|---|
| T | 0.1 s | 与 M08 可比;若能量门不过,升 0.2s 重跑一次(唯一允许的重跑) |
